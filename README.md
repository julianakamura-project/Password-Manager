# Password Manager

A simple **Password Manager** built with Python and Tkinter. This project is part of my studies in GUI programming, with a focus on creating an interactive desktop application and practicing how to connect a graphical interface to Python functionality.

---

## Overview

The application is being developed to make it easier to save and retrieve website login details through a graphical interface. It is also an opportunity to practice organizing a small Python project and working with files.

---

## Planned Features

- [ ] GUI built with Tkinter
- [ ] Input fields for a website, email/username, and password
- [ ] Generate a random password
- [ ] Save login details to a local data file
- [ ] Search for saved login details by website
- [ ] Validate input fields and handle missing information
- [ ] Display confirmations and error messages
- [ ] Use an image/logo in the application interface

---

## Technologies

- **Python** — application logic
- **Tkinter** — graphical user interface
- **File handling** — saving and retrieving data locally

## Getting Started

### Requirements

- Python 3
- Tkinter (usually included with standard Python installations)

### Run the Program

1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Run:

   ```bash
   python main.py
   ```

Depending on your system, you may need to use `python3 main.py` instead.

## Security Note

This is a learning project and should **not** be relied on to store real or sensitive passwords unless appropriate security protections have been implemented and reviewed. A plain-text file such as `data.txt` is not encrypted. Do not commit personal credentials or other secrets to a public repository.
